# To Do App — Simple To-Do App

A clean, responsive, and lightweight task management app built with HTML, CSS, and vanilla JavaScript. Organize your day, track your progress, and keep your tasks saved directly in your browser.

## ✨ Features

- **Add Tasks** — Quickly create tasks with a simple input field.
- **Mark as Completed** — Check off tasks as you finish them.
- **Delete Tasks** — Remove individual tasks whenever you need.
- **Filter Tasks** — View all, active, or completed tasks.
- **Task Statistics** — Track total, active, and completed tasks.
- **Clear Completed** — Remove all completed tasks in one action.
- **Persistent Storage** — Tasks remain saved in your browser using `localStorage`, even after refreshing the page.
- **Responsive Design** — Works across desktop, tablet, and mobile screens.
- **Accessible Interface** — Includes labeled controls, keyboard-friendly interactions, and accessible task updates.
- **Lightweight and Fast** — No frameworks, backend, or build tools required.

## 💻 Getting Started

### Prerequisites

You only need a modern web browser and Git (optional).

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/itsrazakhan/todo-app.git
   ```

2. Navigate to the project directory:

   ```bash
   cd todo-app
   ```

3. Open `index.html` in your browser.

   Alternatively, use the **Live Server** extension in Visual Studio Code for a convenient local development experience.

That's it! No package installation, compilation, or server configuration is required.

## 📖 How to Use

1. **Add a task:** Enter a task in the input field and click **Add Task**. You can also press Enter.
2. **Complete a task:** Select the checkbox beside a task to mark it as completed.
3. **Delete a task:** Click the **Delete** button next to the task you want to remove.
4. **Filter tasks:** Use **All**, **Active**, or **Completed** to view specific tasks.
5. **Track progress:** Check the task summary to see how many tasks are total, active, and completed.
6. **Clear completed tasks:** Click **Clear Completed** to remove every completed task.

## 💾 Data Storage

TaskFlow uses the browser's `localStorage` API to save tasks on your device.

- Tasks persist across page reloads in the same browser and origin.
- No account or database is required.
- Tasks are stored locally rather than synchronized across devices.
- Clearing browser site data may remove saved tasks.
- Private browsing, browser restrictions, or unavailable storage can affect persistence.
